# AI Companions : jeux de révision (anglais)

Cinq jeux en ligne pour réviser le vocabulaire et les formules de débat sur les
AI girlfriends et les griefbots, pour des élèves de niveau B1-B2.

| Jeu | Objectif |
|---|---|
| 1. Texte à trous | Vocabulaire clé (glisser-déposer ou clic) |
| 2. Trier les arguments | Associer chaque argument au camp pour ou contre |
| 3. Traduction FR vers EN | QCM sur les phrases de débat à réutiliser |
| 4. Compréhension orale | Identifier la phrase entendue |
| 5. Rebuttal Arena | Choisir la meilleure riposte (concede & rebut) |

## Mise en ligne

Le site est publié via GitHub Pages : branche `main`, dossier racine.
Fichier principal : `index.html` (page autonome, aucune dépendance externe).

## Fichiers audio du jeu 4

Placer dans le dossier `audio/` huit fichiers nommés `g4_1` à `g4_8`,
au format `.mp3` (prioritaire) ou `.wav` :

1. Aiva never says no.
2. The company charged one dollar per minute.
3. This house believes that AI companions do more good than harm to society.
4. Grief is not a bug; it is the process that lets us rebuild our lives.
5. I take my opponent's point; however, comfort is not the same as healing.
6. The dead cannot consent to being recreated as a chatbot.
7. Loneliness is a public-health crisis.
8. Grief must have an endpoint.

Tant que ces fichiers sont absents, le jeu 4 utilise la synthèse vocale du
navigateur comme solution de repli.
